# 車両管理ダッシュボード (モックアップ)

このリポジトリには、車両の点検・見積・メンテナンス情報を一元管理するためのダッシュボード・モックアップが含まれています。静的な HTML / CSS / JavaScript で構築されており、UI イメージと画面遷移を素早く検証する目的で利用できます。

## 主な画面

- **ダッシュボード**: 登録車両数、点検予定数、見積総額、メンテナンス進捗などのハイライトを表示。今週のアクションタイムラインと車両稼働状況テーブルを確認できます。
- **点検管理**: 点検予定をステータスでフィルタリング可能。詳細ボタンから点検項目のモーダルを表示。
- **見積管理**: 顧客別の見積一覧。金額や状態に応じて絞り込みが可能。
- **メンテナンス管理**: 整備案件を一覧化し、外注先やメモを確認できます。

どの一覧も「詳細」ボタンでサイドドロワーが開き、関連情報が確認できます。また、クイックアクションから新規登録フォームのモックアップを呼び出せます。

## 使い方

1. 任意の HTTP サーバで `index.html` を配信します。開発中は以下のコマンドが簡単です。
   ```bash
   npm install
   npm run start
   ```
   上記コマンドは Python の簡易 HTTP サーバをポート `5173` で起動します。
2. ブラウザで `http://localhost:5173` を開きます。

※外部 API との連携はまだ行っていないため、表示されるデータはすべてスタティックなサンプルです。
